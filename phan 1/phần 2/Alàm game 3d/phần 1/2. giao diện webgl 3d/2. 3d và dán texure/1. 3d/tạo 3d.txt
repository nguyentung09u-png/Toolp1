Làm web gl có nhà 3d chính giữa

Tổng quan cách làm:

1. Tạo Hình học (Geometry): Khởi tạo các khối cơ bản (Hộp, Cầu, Trụ...) bằng các lớp có sẵn của Three.js.
2. Tạo Vật liệu (Material): Khởi tạo vật liệu (màu sắc, độ nhám, texture) để quy định bề mặt.
3. Tạo Lưới (Mesh): Kết hợp Hình học và Vật liệu thành một đối tượng 3D (new THREE.Mesh(geometry, material)).
4. Biến đổi (Transform): Gán các thuộc tính position, rotation, scale cho đối tượng.
5. Đưa vào cảnh: Dùng scene.add() để hiển thị.

Dưới đây là code mẫu chung:

```html
<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <style>body { margin: 0; overflow: hidden; }</style>
</head>
<body>
<script src="https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js"></script>
<script>
  // 1. Khởi tạo cảnh, camera, renderer
  const scene = new THREE.Scene();
  const camera = new THREE.PerspectiveCamera(60, innerWidth / innerHeight, 0.1, 1000);
  camera.position.set(0, 0, 5);
  const renderer = new THREE.WebGLRenderer({ antialias: true });
  renderer.setSize(innerWidth, innerHeight);
  document.body.appendChild(renderer.domElement);

  // 2. Geometry (Hình khối hộp)
  const geometry = new THREE.BoxGeometry(1, 1, 1);

  // 3. Material (Vật liệu màu xanh lam)
  const material = new THREE.MeshStandardMaterial({ color: 0x38bdf8 });

  // 4. Mesh (Kết hợp)
  const mesh = new THREE.Mesh(geometry, material);

  // 5. Transform (Vị trí, xoay, tỷ lệ)
  mesh.position.set(0, 0, 0);
  mesh.rotation.set(0.5, 0.5, 0);
  mesh.scale.set(1, 1.5, 1); // Kéo dài theo trục Y

  // 6. Đưa vào cảnh
  scene.add(mesh);

  // Thêm ánh sáng cơ bản để nhìn thấy khối 3D
  scene.add(new THREE.AmbientLight(0xffffff, 1));

  // 7. Vòng lặp render
  function animate() {
    requestAnimationFrame(animate);
    mesh.rotation.y += 0.01; // Xoay liên tục
    renderer.render(scene, camera);
  }
  animate();
</script>
</body>
</html>
```
